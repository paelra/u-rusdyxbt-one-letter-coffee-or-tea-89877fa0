# u-rusdyxbt-one-letter-coffee-or-tea-89877fa0

A tiny program with one strong opinion. Given a single letter to speak
for an entire drink, it chooses coffee — the bold, first-sip-of-the-morning
kind of choice — and writes that lone letter to the output file.

## Run it

```sh
node main.ts
```

This creates `/output/entry.txt` containing exactly one character: the letter chosen for coffee. No extra words, no decoration — just the pick itself.
